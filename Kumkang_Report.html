कार्य सारांश (Executive Summary)

Kumkang प्रोजेक्ट मॉनिटरिंग वेबसाइटमध्ये खालील मुख्य सुधारणा करून देण्यात आल्या — ड्युअल लॉगिन पोर्टल (Developer / Staff / Client), रिअल वर्ल्ड ग्लोबल मॅप (खऱ्या भौगोलिक नकाशावर), स्वच्छ प्रोजेक्ट जर्नी स्टेटस कॉम्पोनंट्स, क्लायंट-विशिष्ट सुरक्षित डॅशबोर्ड, करन्सी स्विचर (USD/INR/KRW), आणि डेव्हलपर अ‍ॅक्सेस व क्रेडेन्शियल व्यवस्थापन. डेव्हलपर लॉगिनसाठी तात्पुरते लोकल PIN 77 कॉन्फिगर केले गेले आणि Developer popup वर मॅप येण्याचा (overlap) बग दुरुस्त केला गेला.

प्रामाणिक मर्यादा (Honest Limitations)

  • हे प्रकल्प ब्राउझर-आधारित prototype आहे — कोणताही backend server किंवा database नाही. युजर लॉगिन-इव्हंट्स व क्लायंट डेटा browser च्या localStorage मध्ये सुरक्षितपणे (hashed) साठवले जातात.
  • Staff / Admin / PM login विद्यमान role-switch मॉडेलवर आधारित आहे (हे पूर्वीचेच आहे, बदलले नाही). हे फक्त Admin/PM देतात — Developer कधीही नाही.
  • UI click-through (Developer → 77 → login) automated browser test-नुसार नाही, तर code + hash-equivalence + runtime verification नुसार तपासले. कोणतीही automation test-harness प्रकल्पात नाही.
